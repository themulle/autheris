# WP-SIMPL-12 Delete external catalog connectors, Backstage, ITSM and break-glass (header flow and profile assignments)
Status: Ready for implementation
Parent: [plan](../2026-11-05-plan-project-simplification.md#wp-simpl-12-delete-external-catalog-connectors-backstage-itsm) | Issues: #485 (ITSM part), #491 (part), #507 (break-glass header part), #515 | Owner decisions: OD-5, OD-17(6), OD-32 (access-profile break-glass assignments removed as well) | Security conditions: SEC-SIMPL-30, 31, 37, 39, 83, 84; advisories GHSA-9229-wx6j-wvm9 (Admin catalog operations), GHSA-jfrx-2mgc-pfh5 (external catalog sync); details: private advisory

## 1. Goal and outcome
Remove Purview, Collibra, Alation, DataHub clients, the Backstage export, the ITSM (ServiceNow/Jira) integration, `JustificationAndBreakGlassInterceptor` (header flow, OD-5) and access-profile break-glass assignments (OD-32) from core. The generic consent-expiry scan (`ConsentRecertificationHostedService`) and the request status `PENDING_EXTERNAL_APPROVAL` stay, decoupled from ITSM, until WP-SIMPL-47 replaces them (R18). Outcome: `git grep -il "purview|collibra|alation|datahub|backstage|JustificationAndBreakGlass" -- src` returns nothing; `itsm` hits in `src` are only the consent-core leftovers owned by WP-SIMPL-47 (section 4); no break-glass assignment kind remains; about -4,400 src lines; every removed route returns 404; every removed config key fails startup.
