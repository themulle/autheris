# Plan: Issue #281 - Runtime-managed, app-scoped trusted GraphQL documents

Phase 2 (architect). Input: [PRD](2026-10-23-prd-issue-281-app-scoped-trusted-documents.md) (REQ-281-1..13), issue #281 owner decisions 1-3 (binding). Verified against `feat/issue-281-app-scoped-trusted-documents` on 2026-10-23.

## Code facts (current branch)
- `TrustedDocumentStore` / `TrustedDocumentsOnlyMiddleware` (`src/Autheris.Api/Middleware/TrustedDocumentsOnlyMiddleware.cs`): HotChocolate request middleware after `UseDocumentCache`, registered only when `GraphQL.PersistedQueriesOnly` (`GatewayServiceCollectionExtensions.cs` ~l.594). Global hash = SHA-256 over the **printed** `DocumentNode` (normalized). Rejection code `TRUSTED_DOCUMENT_REQUIRED`, message fixed.
- `GatewayStartupValidator` (~l.185) requires an existing `TrustedDocumentsDirectory` when `PersistedQueriesOnly`.
- Governance DDL lives in one versioned step per provider (`MigrationStep` 1 `baseline_governance_schema`), built by `{Sqlite,PostgreSql,SqlServer}BaselineSchema.cs`, checked by `Shape/governance-shape.{sqlite,postgresql,sqlserver}.json`.
- Runtime-managed store precedent: `CallerAttributeRegistry` (generation row `CALLER_ATTRIBUTE_GENERATION`, poll every 5 s, local `Invalidate()` on write, fail-closed on load error) + `CallerAttributeAdministrationService` (audit via `IAuditLogRepository`).
- Admin surface: `/api/admin/*` (`TokenRevocationEndpoints`, `TenantRegistryAdminEndpoints`); `AdminIpAllowlistMiddleware` defaults to prefix `/api/admin` but is not wired in the pipeline.
- Scopes: `TokenAccessScope.HasScope(principal, scope)` (`scp`/`scope` claims).
- CORS: `GatewayCoreServiceExtensions.cs` l.115 `.WithHeaders(...)` does not list `X-Autheris-App`.
- HttpContext inside HC middleware: `ContextData["HttpContext"]` with `IHttpContextAccessor` fallback (`CostAndQuotaMiddleware` l.32-40).

## Open questions
- OQ-1 default taken: developer makes minimal edits to `docs/configuration-guide.md` and `docs/endpoints-and-testing.md` in WP3.
- OQ-2 default taken: PUT without at least one allowed origin returns 400; every app is origin-bound.
- OQ-3 default taken, confirmed against code: there is no cross-instance push channel for governance caches; the established mechanism is the DB generation counter polled by each instance (`CallerAttributeRegistry`). Reuse it: write-through `Invalidate()` on the writing instance, generation poll on all others (interval option, default 5 s). No separate TTL.
- OQ-4 default taken: soft retire (status `retired`, row and hashes kept); PUT on a retired version returns 409; repeated DELETE is idempotent (204).
- OQ-5 default taken: read scope `trusted-documents:read`; `trusted-documents:write` also grants GET.
- OQ-6 default taken: header only, no claim-based app identity.
- Architect default (not in PRD): apps are gateway-wide, not tenant-scoped (same reach as the global directory); audit uses `TenantId.LegacySingleTenant`.

## Design decisions
1. **Schema** (REQ-281-1). Four tables appended to each provider baseline (in place, no upgrade step, checksum identity unchanged): `TRUSTED_DOCUMENT_APPS(app_id PK, created_at, updated_at)`, `TRUSTED_DOCUMENT_APP_ORIGINS(app_id FK, origin, PK(app_id, origin))`, `TRUSTED_DOCUMENT_APP_VERSIONS(app_id FK, version, status CHECK IN ('active','retired'), created_at, updated_at, retired_at NULL, PK(app_id, version))`, `TRUSTED_DOCUMENT_HASHES(app_id, version, hash CHAR(64), PK(app_id, version, hash), FK -> versions)`, plus `TRUSTED_DOCUMENT_GENERATION(id=1, generation)` seeded with 0 (same idiom as `CALLER_ATTRIBUTE_GENERATION`). Shape JSON updated for all three providers. Tests: `GovernanceSchemaShapeSnapshotTests` (unit, updated), `{PostgreSql,SqlServer}GovernanceSchemaShapeTests` (integration, CI).
2. **Repository** `ITrustedDocumentRepository` (`src/Autheris.Domain/Interfaces/`): `GetGenerationAsync`, `LoadActiveSnapshotAsync` (active versions + hashes + origins), `ListAppAsync(appId)`, `ReplaceVersionSetAsync(appId, version, origins, hashes) -> TrustedDocumentSetDelta(added, removed, created)` (one transaction: upsert app, replace origins, reject retired with `TrustedDocumentVersionRetiredException`, diff hashes, bump generation), `RetireVersionAsync(appId, version) -> RetireOutcome(NotFound|Retired|AlreadyRetired)` (bumps generation). Implemented as partials `{Provider}GovernanceRepository.TrustedDocuments.cs`, registered like `ICallerAttributeRepository` (`GatewayGovernanceServiceExtensions.cs` ~l.385). Tests: `SqliteTrustedDocumentRepositoryTests` (unit: replace/diff, idempotent re-PUT gives empty delta, retire, retired re-PUT throws, generation bump), `{PostgreSql,SqlServer}TrustedDocumentRepositoryTests` (integration).
3. **Exact-text hash** (owner decision 3). New `TrustedDocumentHash.ComputeExact(ReadOnlySpan<byte> utf8)` -> lower-case hex SHA-256. App-scoped path hashes the UTF-8 bytes of the request's source text (`context.Request.Document` as `OperationDocumentSourceText`). Requests without source text (id-only, pre-parsed) are rejected on the app-scoped path. Global path keeps its normalized hash unchanged (REQ-281-10). Test: `TrustedDocumentHashTests` (whitespace change changes hash; known vector).
4. **Header parsing** `AppIdentityHeader.TryParse(StringValues, out AppIdentity)` (`src/Autheris.Api/Middleware/`): exactly one value, `<appId>/<version>`, appId `^[a-z0-9][a-z0-9._-]{0,63}$`, version `^[A-Za-z0-9][A-Za-z0-9._+-]{0,63}$`, total <= 129 chars, ordinal. Same regexes validate admin route values (source-generated `[GeneratedRegex]`). Test: `AppIdentityHeaderTests` (valid, missing slash, two slashes, empty part, oversize, illegal chars, upper-case appId, two header values).
5. **Origin normalization** `AllowedOrigin.TryNormalize(string, out string)`: absolute `http`/`https` URI, no userinfo/path (except `/`)/query/fragment, lower-case scheme and host, default port elided -> `scheme://host[:port]`. Used for PUT input (max 10 per app, else 400) and request `Origin` comparison (ordinal equality). Missing `Origin`, `null` origin or mismatch -> reject. Test: `AllowedOriginTests`.
6. **Registry** `TrustedDocumentAppRegistry` (`src/Autheris.Application/Governance/TrustedDocuments/`), singleton, clone of the `CallerAttributeRegistry` pattern: immutable snapshot `FrozenDictionary<AppIdentity, FrozenSet<string>>` + `FrozenDictionary<string, FrozenSet<string>>` origins; `Invalidate()`; generation poll interval `CacheRefreshSeconds`; load failure clears staleness and rethrows. Tests: `TrustedDocumentAppRegistryTests` (fresh load, cached within interval, reload after `Invalidate`, reload after generation change via `FakeTimeProvider`, repository throw propagates and next call retries, retired version absent).
7. **Middleware extension** (REQ-281-5/6/7/9/10/12). `TrustedDocumentsOnlyMiddleware.InvokeAsync`: when `AppScopedTrustedDocuments.Enabled` and the header key is present (any value), resolve HttpContext (pattern of `CostAndQuotaMiddleware`), then parse header -> check origin -> compute exact hash -> `registry.GetAsync` lookup; any failure (parse, origin, unknown app/version/hash, no source text, registry exception) yields the **existing** error (same message, code `TRUSTED_DOCUMENT_REQUIRED`), never falls back to the global store. Header absent -> existing global path unchanged. Log at Debug only appId/version/hash and a reason enum, never document text. Applies to WebSocket via the upgrade request headers. Tests: `TrustedDocumentsOnlyMiddlewareAppScopeTests`: `Registered_A1_Runs_For_A1`, `Rejected_For_A2`, `Rejected_For_B1`, `NoHeader_UsesGlobalStore`, `Retired_Rejected`, `Malformed_Rejected_NoGlobalFallback` (hash also in global store), `MultipleHeaderValues_Rejected`, `OriginMismatch_Rejected`, `OriginMissing_Rejected`, `RegistryThrows_Rejected`, `NormalizedVariant_Rejected` (exact text only), `AllRejections_IdenticalErrorShape`, `Disabled_HeaderIgnored_GlobalPathUnchanged`, `CacheRefresh_NewSetAcceptedAfterInvalidate`.
8. **Options** (REQ-281-11). `GraphQLOptions.AppScopedTrustedDocuments` (`AppScopedTrustedDocumentsOptions`): `Enabled` (false), `HeaderName` ("X-Autheris-App", RFC 7230 token), `MaxHashesPerVersion` (500, range 1-5000), `MaxActiveVersionsPerApp` (20, 1-200), `MaxAllowedOriginsPerApp` (10, 1-50), `CacheRefreshSeconds` (5, 1-60). `GatewayStartupValidator`: `Enabled` requires `PersistedQueriesOnly=true`; when `Enabled`, `TrustedDocumentsDirectory` may be empty (empty global store = header-less requests rejected); a non-empty but missing directory still fails. Tests: `GatewayStartupValidatorAppScopedTests`.
9. **CORS**: when enabled, append the configured `HeaderName` to `.WithHeaders(...)` in `GatewayCoreServiceExtensions`. Test: preflight with the header allowed only when enabled.
10. **Admin service** `TrustedDocumentAdministrationService` (Application): validates inputs (64 hex -> lower case, de-duplicated, 1..MaxHashesPerVersion; origins per decision 5, >= 1; active-version cap -> 409), calls repository, `registry.Invalidate()`, then `AuditWriter.RecordRequiredAsync` with new event types `TRUSTED_DOCUMENTS_REPLACED` / `TRUSTED_DOCUMENTS_RETIRED` (`AuditEventTypes`): actor sid, `TargetTable = "trusted-documents:{appId}/{version}"`, details JSON `{appId, version, addedCount, removedCount, added[], removed[], originsChanged}` - no document text. Idempotent re-PUT with empty delta is audited too (actor trace). Tests: `TrustedDocumentAdministrationServiceTests` (validation 400 cases, retired 409, cap 409, audit payload shape, invalidate called, audit failure surfaces as error).
11. **Admin endpoints** `TrustedDocumentAdminEndpoints.MapTrustedDocumentAdminEndpoints` mapped in `GatewayApplicationBuilderExtensions` next to `MapTenantRegistryAdminEndpoints` **only when enabled**: `PUT /api/admin/trusted-documents/{appId}/{version}` body `{hashes[], allowedOrigins[]}` -> 200 `{added, removed, unchanged}`; `DELETE ...` -> 204 / 404; `GET /api/admin/trusted-documents/{appId}` -> 200 versions with status and hash counts / 404. Path deviates from the issue (`/admin/...`) to sit on the existing `/api/admin` surface. Policies `GatewayPolicies.TrustedDocumentsWriter` (authenticated + scope `trusted-documents:write`) and `TrustedDocumentsReader` (read or write scope); unauthenticated -> 401, missing scope -> 403; body size limit 256 KiB. Tests: `TrustedDocumentAdminEndpointsTests` (unit, `TestServer`/`TestAuthHandler` scp header): `Put_WithoutScope_403`, `Put_ReadScope_403`, `Get_ReadScope_200`, `Put_InvalidHash_400`, `Put_NoOrigins_400`, `Put_Retired_409`, `Routes_Absent_When_Disabled_404`, `Put_Then_GraphQl_Accepts_Without_Restart`. Integration: `TrustedDocumentAdminApiIntegrationTests` (PostgreSql, SqlServer; CI only) incl. audit row assertion.
12. **Exposure** (REQ-281-3): Phase 3 to decide whether to wire the existing `AdminIpAllowlistMiddleware` for `/api/admin`; WP3 adds a test that the Helm default ingress paths do not route `/api/admin` (`IngressEgressTests`).

## Phase 3 security conditions
Reviewer: csharp-security-expert, 2026-10-23. Verified: `TrustedDocumentsOnlyMiddleware` runs after `UseDocumentCache`; the global path hashes the re-printed `DocumentNode`; `AdminIpAllowlistMiddleware` is unwired, has an empty default list (no-op) and no option source; admin endpoints use `GatewayPolicies.ClusterAdmin`.

**Verdict: APPROVED WITH CONDITIONS.**

- **SEC-281-1 (executed == hashed).** The app path hashes `Request.Document` source text only. It must reject (uniform error) when the request also carries `DocumentId`/`DocumentHash`, an APQ `persistedQuery` extension, or a pre-parsed document (`OperationDocumentInfo.Document` set without source text). A hash-id-only request is never trusted on the app path. The hash is computed over the exact UTF-8 bytes of the text that the parser later consumes (no re-read, no trimming, no normalisation); the document-cache key must be derived from that same text. Operation selection via `operationName` is allowed because the whole hashed document is trusted; batch/array requests are evaluated per item with the same header and Origin.
- **SEC-281-2 (no downgrade).** App header present (any value, including empty) means app path only. No fallback to the global store or to no-header behaviour on any failure. Disabled feature: the header is ignored and the global path is unchanged. The global hash algorithm is not touched.
- **SEC-281-3 (origin, fail-closed).** With the app header present, a missing, `null`, duplicated or non-normalisable `Origin` is rejected; there is no non-browser exemption (server clients must send the registered Origin). Exact ordinal match after `AllowedOrigin.TryNormalize` of the request value. Never use `Referer`, `Host` or forwarded headers. WebSocket uses the upgrade request `Origin`.
- **SEC-281-4 (uniform rejection).** All app-path failures (parse, origin, unknown/retired app/version/hash, no source text, registry error) return an identical `TRUSTED_DOCUMENT_REQUIRED` result: same message, code, extensions, status; no reason in the response. Debug log carries only a reason enum plus the validated appId/version; never header raw value beyond the length cap, never document text.
- **SEC-281-5 (header bounds).** Reject exactly one value, length <= 129 before any regex; regexes are `[GeneratedRegex]` with `RegexOptions.CultureInvariant` and a match timeout; the raw value is truncated/omitted in logs; the same validators apply to admin route values (reject 400, no echo of the value beyond a code).
- **SEC-281-6 (admin authz and exposure).** All admin routes use `RequireAuthorization(ClusterAdmin)` plus an explicit scope check: PUT/DELETE need `trusted-documents:write`, GET needs read or write; missing scope returns 403 (ProblemDetails `AccessDenied`), unauthenticated 401. Routes are mapped only when the feature is enabled. `AdminIpAllowlistMiddleware` is NOT wired in this issue (no config source, empty list is a no-op, would be a false control); cluster-internal reachability is enforced by ingress: the WP3 `IngressEgressTests` check (no `/api/admin` route in default Helm ingress, incl. wildcard/prefix `/`-only rules not exposing it) is mandatory. Follow-up item recorded: allowlist configuration for `/api/admin`.
- **SEC-281-7 (registry coherence/DB failure).** Load error or generation-read error fails closed: the middleware rejects, the previous snapshot is not served once a refresh is due and has failed (clone `CallerAttributeRegistry` semantics: clear staleness, rethrow). The retire window of up to `CacheRefreshSeconds` (default 5 s) on other instances is accepted and must be documented; the writing instance invalidates synchronously before returning 2xx. Poll jitter-free, single-flight refresh (one DB read per interval, no stampede). The generation row is bumped in the same transaction as the mutation.
- **SEC-281-8 (scope and bounds).** Apps are gateway-wide (accepted; documented). Enforce server-side: hashes 1..MaxHashesPerVersion, 64 lower-case hex (case-fold on input), origins 1..10, request body size cap on PUT (<= 1 MiB), active-version cap; retired versions rejected by lookup and by PUT (409). Registry lookup is by exact `AppIdentity` key (no prefix/wildcard).
- **SEC-281-9 (audit).** Required audit (fail the request when the audit write fails, after the DB commit is reported as error to the caller and the cache invalidated anyway) for PUT/DELETE including no-op re-PUT. Details carry hashes (not secrets, acceptable), counts, originsChanged, actor sub and scope; list lengths capped (e.g. 500 per list, else counts only). No document text, no token material.
- **SEC-281-10 (CORS).** `X-Autheris-App` is added to allowed headers only when enabled; CORS never substitutes for the Origin check.
