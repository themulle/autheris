# Plans Directory (Retired)

`docs/plans/` is **retired** for new requirements, implementation plans, roadmaps, and work logs.

- **All new requirements, implementation details/plans, security conditions, and operational work instructions (such as code reviews)** are managed exclusively in **GitHub Issues** (`gh issue`).
- Implementation plans and PRDs are attached directly to their GitHub Issue (in the issue body or as a structured `## Implementation Details` comment) — never committed as files under `docs/plans/`.
- Agents coordinate across machines directly on GitHub Issues using the `in-progress` label and claim comments (see [AGENTS.md](../../AGENTS.md)).
- Only [`2026-10-23-plan-nightly-parity-tests.md`](2026-10-23-plan-nightly-parity-tests.md) remains here for the `PARITY-GAP-*` registry checked by `ParityIsolationArchitectureTests`.
