## 1. Overview & Problem Statement

Even with semantic descriptions, LLMs frequently struggle with intricate multi-table joins, temporal filter logic, and dialect nuances. F-AI-03 dynamically injects curated, verified 'Golden Queries' (few-shot examples) into the tool descriptions and prompt templates delivered to AI agents. When an agent explores available tools, it receives verified examples of syntax, parameter formatting, and join patterns for the specific requested data domain.

---

## 2. Business Value

- **95%+ First-Shot Query Accuracy**: Eliminates iterative LLM retry loops caused by syntax errors, reducing LLM token consumption and latency.
- **Knowledge Curation**: Domain experts and Data Stewards define authoritative query patterns that steer AI agents toward certified organizational best practices.
- **Compute Cost Savings**: Prevents expensive, inefficient unindexed table scans generated by naive model-generated queries.

---

## 3. Architecture & Capabilities

- Curated repository of certified GraphQL and SQL queries indexed by domain and table identifier.
- Dynamic injection into MCP tool metadata formatted as few-shot prompt demonstrations.
- Verification hooks ensuring golden queries comply with active schema contracts and Casbin ABAC constraints.

---

## 4. Usage Example

```bash
# Retrieve tool prompt definitions with injected few-shot examples
curl -X POST http://localhost:8080/mcp \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <agent-token>" \
  -d '{
    "jsonrpc": "2.0",
    "id": 2,
    "method": "prompts/get",
    "params": {
      "name": "sales_analytics_assistant"
    }
  }'

# Returned prompt includes certified Few-Shot Golden Queries:
# Example 1: Top 10 Enterprise Customers by ARR:
# query { topCustomers(minArr: 100000, limit: 10) { customerId name arr contractEndDate } }
```

---

## 5. Configuration Example

```json
{
  "Gateway": {
    "Mcp": {
      "GoldenQueries": {
        "Enabled": true,
        "MaxExamplesPerTool": 3,
        "Directory": "config/golden-queries",
        "AutoValidateOnStartup": true
      }
    }
  }
}
```
