# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Autheris team takes the security of our software seriously. If you believe you have found a security vulnerability, please report it to us responsibly.

**Please do NOT report security vulnerabilities through public GitHub issues.**

Instead, please use one of the following channels:
1. **GitHub Private Vulnerability Reporting**: Open an advisory privately via the "Security" -> "Report a vulnerability" tab on GitHub.
2. **Email**: Contact the security team directly at `security@autheris.io`.

### What to Include in Your Report
- A description of the vulnerability and its potential impact.
- Detailed step-by-step instructions or proof-of-concept code to reproduce the issue.
- Any relevant logs, stack traces, or configuration details.

### Response Timeline
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide regular updates on our progress in validating and fixing the issue.
- Coordinated public disclosure will take place once a fix or mitigation is available.
